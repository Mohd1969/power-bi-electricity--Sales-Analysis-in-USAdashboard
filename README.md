# ⚡ Electricity Sales Analysis in USA (2007)

This Power BI report presents a detailed analysis of electricity sales across U.S. states and entities in 2007. The dashboard provides insights into total sales, revenue, pricing, and customer distribution using interactive visuals and KPIs.

## 📊 Key Features

- **Total Sales (Megawatthours)** by Entity and State
- **Total Revenue (Thousands of Dollars)** by Ownership Type and State
- **Average Price (Cents/kWh)** Trends
- **Customer Distribution** across Ownership Types
- **Interactive Filters** (State, Ownership, Entity)

## 📌 Pages Included

- ✅ Report Cover  
- ✅ Summary Page  
- ✅ Dashboard Page  

## 🛠️ Tools Used

- Power BI Desktop
- Microsoft Excel (Data source)
- GitHub for version control and sharing

## 🧠 Insights

- States like **Texas**, **Florida**, and **California** dominate sales and revenue.
- **Investor-Owned utilities** contribute the majority of total revenues.
- Wide variation exists in **average electricity prices** by ownership type.
